# FastRent

FastRent — веб-сайт для поиска и бронирования квартир. Приложение написано на Java и запускает локальный сайт с каталогом, регистрацией и входом, личным кабинетом гостя и отдельной панелью администратора.

## Запуск

1. Откройте проект в IntelliJ IDEA с JDK 21 или новее.
2. Откройте `src/Main.java` и запустите `Main.main()`.
3. Перейдите по адресу [http://localhost:8080](http://localhost:8080).

Демо-вход администратора: `admin@fastrent.ru`, пароль `FastRent2026!`. Новый пользователь может создать аккаунт на сайте. Администратор управляет каталогом квартир и видит бронирования; гости создают и отменяют собственные бронирования.

Пользователи, каталог и бронирования сохраняются локально в `data/fastrent.properties`. Файл создаётся при первом изменении данных и исключён из Git.
