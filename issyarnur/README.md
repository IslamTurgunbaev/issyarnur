# FastRent

FastRent — веб-сайт для поиска и бронирования квартир. Приложение написано на Java и запускает локальный сайт с каталогом, регистрацией и входом, личным кабинетом гостя и отдельной панелью администратора.

## Запуск

1. Откройте проект в IntelliJ IDEA с JDK 21 или новее.
2. Откройте `src/Main.java` и запустите `Main.main()`.
3. Перейдите по адресу [http://localhost:8080](http://localhost:8080).

Демо-вход администратора: `admin@fastrent.ru`, пароль `FastRent2026!`. Новый пользователь может создать аккаунт на сайте. Администратор управляет каталогом квартир, бронированиями и публикациями (статьи, фото, видео и рекламные карточки); гости создают и отменяют собственные бронирования. Опубликованные материалы появляются в журнале на главной странице, а реклама отображается отдельным заметным блоком.

Пользователи, каталог, бронирования и публикации сохраняются локально в `data/fastrent.properties`. Медиафайлы указываются ссылками на `http://` или `https://`; файлы создаются и размещаются отдельно. Файл данных создаётся при первом изменении данных и исключён из Git.
